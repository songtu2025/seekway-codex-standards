# SEEKWAY Codex 开发任务模板

使用者只需填写业务背景、当前情况、目标和验收标准。技术项不确定时保留“由 Codex 分析”。

## 任务背景

填写修改原因。

## 当前情况

填写当前功能、问题和复现方式。

## 目标结果

填写完成后的可观察结果。

## 验收标准

1. 待填写。

## Web 界面影响

- 是否涉及界面：是 / 否。
- 设计来源：无 / Figma / 截图 / 现有相似页面 / 其他。
- 目标视口：继承 `docs/web-ui-standard.md` 的项目配置；本任务存在例外时填写具体差异。
- 额外页面状态：继承任务命中的表单或数据专项规范；存在特殊业务状态时填写，不重复默认状态清单。
- 是否需要移动端：否；如需要，必须明确目标视口和布局要求。

涉及界面时附上设计稿、截图或相似页面位置。没有视觉来源时，复用项目规范和已有页面，不得另创视觉方向。

## 是否允许新增生产依赖

- 新 Web 项目允许 `antd@6` 和 `@ant-design/icons@6`；现有项目接入基线或新增其他生产依赖时，Codex 必须说明原因并获得确认。

## 配置和部署影响

数据库、权限、认证、依赖、配置或部署已有明确影响时，填写具体范围；配置中不得填写真实生产凭据。
