## Web 界面影响

- 是否涉及界面：是 / 否。
- 设计来源：无 / Figma / 截图 / 现有相似页面 / 其他。
- 目标视口：继承 `docs/web-ui-standard.md` 的项目配置；本任务存在例外时填写具体差异。
- 额外页面状态：继承任务命中的表单或数据专项规范；存在特殊业务状态时填写，不重复默认状态清单。
- 是否需要移动端：否；如需要，必须明确目标视口和布局要求。

涉及界面时附上设计稿、截图或相似页面位置。没有视觉来源时，复用项目规范和已有页面，不得另创视觉方向。

## 是否允许新增生产依赖

- 新 Web 项目允许 `antd@6` 和 `@ant-design/icons@6`；现有项目接入基线或新增其他生产依赖时，Codex 必须说明原因并获得确认。

如允许，填写依赖名称和原因。

如已知有影响，填写配置项，但不得填写真实生产凭据。

## Codex 执行要求

先按 `AGENTS.md` 索引读取相关规范，再阅读 README、需求、代码和测试。非简单任务修改前输出：

1. 对需求和验收标准的复述。
2. 调用链、现有实现和可复用能力。
3. 修改文件及内容。
4. 数据库、权限、配置、依赖和部署影响。
5. 风险、回滚方式和验证方案。
6. 涉及界面时，说明设计来源、复用内容、页面状态和目标视口。

获得确认后按最小修改原则实施。边界明确且不涉及数据库、认证、权限、配置、依赖或部署的简单任务可直接实施。完成报告按 `docs/codex/verification.md` 的五项格式输出。
